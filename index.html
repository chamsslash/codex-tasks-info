Codex Tasks

Личное приложение для работы с Google Задачами из Codex на компьютере пользователя. По запросу владельца аккаунта оно показывает списки, создаёт задачи, обновляет сроки и отмечает выполненные дела.

Пользователь выбирает Google-аккаунт и предоставляет доступ через экран согласия Google. Операции выполняет локальный MCP-сервер через Google Tasks API.
